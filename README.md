# Ryze · ressources publiques

Bienvenue sur le profil GitHub de **Ryze Systems**. Ce dépôt rassemble des liens vers les sites publics de l’écosystème et une méthode de vérification web utilisable par une petite équipe.

## Ressource pratique

[Vérifier l’accessibilité d’un site aux moteurs et aux réponses IA](guides/verifier-accessibilite-seo-geo.md) : une checklist avec méthodes, preuves à conserver et modèle de compte rendu. Elle aide à distinguer un problème technique, une information incohérente et un résultat encore non mesuré.

[Du besoin au logiciel](guides/du-besoin-au-logiciel.md) : une fiche de cadrage, des critères de réception et un exemple fictif pour préparer un premier pilote.

## À propos de ces ressources

Les documents sont publiés par Ryze. Ils ne constituent pas une évaluation indépendante des produits. Les exemples pédagogiques sont indiqués comme fictifs et les observations doivent être datées. Aucun classement ni aucune citation par un moteur de recherche ou un assistant IA n’est garanti.

Pour proposer une correction à la documentation, ouvrez une issue ou une pull request dans ce dépôt, sans joindre de donnée personnelle ni de secret.

*Liens et présentations vérifiés sur les pages publiques le 17 octobre 2026.*
